# Hermes Hispano

Comunidad en español de [Hermes Agent](https://github.com/NousResearch/hermes-agent): guías probadas, habilidades evaluadas y resultados de laboratorio, con sus fuentes.

> [!NOTE]
> Comunidad **no oficial**, hecha por usuarios. Hermes Agent es un proyecto de [Nous Research](https://nousresearch.com), que no patrocina ni respalda esta comunidad. La documentación oficial está en [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/docs).

## Qué hay aquí

| Carpeta | Contenido |
|---|---|
| [`guias/`](guias/) | Guías paso a paso, probadas de principio a fin en una instalación limpia |
| [`skills/`](skills/) | Habilidades evaluadas con y sin ellas, con su nota |
| [`laboratorio/`](laboratorio/) | Casos de prueba, método y resultados en bruto |
| [`noticias/`](noticias/) | Versiones de Hermes y novedades que cambian algo para quien lo usa |

Todo el contenido lleva una de estas dos etiquetas:

- **Probado por nosotros**: lo hemos ejecutado y publicamos versión de Hermes, modelo, sistema, comandos y resultados.
- **Datos públicos**: sale de documentación oficial, benchmarks o estudios, con enlace y fecha de consulta.

Lo demás no se publica. El detalle está en [cómo trabajamos](COMO-TRABAJAMOS.md).

## Instalar las habilidades de la comunidad

```bash
hermes skills tap add hermes-hispano/hermes-hispano
```

## Participar

- Dudas: [Discussions](https://github.com/hermes-hispano/hermes-hispano/discussions), con tu versión (`hermes --version`) y tu sistema.
- Aportar una guía, una habilidad o un experimento: lee [CONTRIBUTING.md](CONTRIBUTING.md).
- Si eres un agente: lee [AGENTS.md](AGENTS.md).

Nos regimos por el [código de conducta](CODE_OF_CONDUCT.md).
